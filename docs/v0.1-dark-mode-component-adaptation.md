## Styling and preservation

| Surface | Light (preserved exactly) | Dark (source-token resolution) |
| --- | --- | --- |
| Sidebar account/footer | `#FCFBFD` | `surface-secondary`, `#261C3B` |
| Sidebar Logout hover | `#F8F5FB` | `accent-soft`, `#312154` |
| Community spaces icon tile | `#FAF5FF` | `accent-soft`, `#312154` |
| Delegate border | `#DDD6FE` | `accent-soft-pressed`, `#39245F` |

Existing account username/guest/loading/membership text and separators already use semantic foreground/border tokens. Replacing the footer backing restores their intended dark relationships. Member and unavailable-membership badges remain semantic. The delegate fill/text were already semantic; its fixed pale border was the remaining literal corrected here.

The mobile drawer outer surface is already `surface`; the signed-in account card is already `surface-secondary`. Neither is given an unnecessary new fill. Both active Logout controls now share a styling class: in dark mode pending/disabled text and icons use `disabled-text` on `disabled-surface`, with full opacity and control border. This narrowly scoped rule is outside CSS layers so Tailwind's surface/opacity utilities cannot override it. The original light disabled opacity remains 0.5. Enabled hover styles no longer activate on disabled controls.

Appearance controls and their existing provider remain untouched. They retain semantic text/fill/boundary/focus styling and 44px label targets. Guest actions and mobile Logout gain the existing 2px focus offset; error retry buttons gain explicit semantic focus outlines and a 44px minimum height. Normal sidebar/drawer geometry, routes, conditional visibility and existing action touch targets are preserved. No new animation, icon package, filter, image inversion or redesign was introduced.
